C) ACCESS & CREDENTIALS YOU NEED TO PROVIDE
================================================================================

Copy values into .env on the Asoldi server (never commit secrets to git).

--- 1) GOOGLE OAUTH (client login) ---
[ ] GOOGLE_CLIENT_ID=
[ ] GOOGLE_CLIENT_SECRET=
[ ] Authorized redirect URI(s) added in Google Cloud Console, e.g.:
      https://asoldi.com/api/client/auth/google/callback
      http://localhost:3000/api/client/auth/google/callback  (dev)

How: Google Cloud Console → APIs & Services → Credentials → OAuth 2.0 Client ID

--- 2) FACEBOOK OAUTH (client login) ---
[ ] FACEBOOK_APP_ID=
[ ] FACEBOOK_APP_SECRET=
[ ] Valid OAuth redirect URI(s) in Meta Developer app, e.g.:
      https://asoldi.com/api/client/auth/facebook/callback

How: developers.facebook.com → Your App → Facebook Login → Settings

--- 3) SMTP (password reset + sales emails) ---
[ ] SMTP_HOST=
[ ] SMTP_PORT=          (usually 587 or 465)
[ ] SMTP_USER=
[ ] SMTP_PASS=
[ ] SMTP_FROM=          (e.g. noreply@asoldi.com — domain must be verified)
[ ] APP_URL=https://asoldi.com   (for correct reset links in emails)

How: Use your email provider (Hostinger, Google Workspace, SendGrid, etc.)

--- 4) GOOGLE CALENDAR (sales meetings — Admin > Sales) ---
[ ] GOOGLE_CALENDAR_CLIENT_ID=
[ ] GOOGLE_CALENDAR_CLIENT_SECRET=
[ ] GOOGLE_CALENDAR_REDIRECT_URI=   (match server callback route)
[ ] First connect: open Admin → Sales → Connect Google Calendar (one-time OAuth)

How: Same or separate Google Cloud project; enable Calendar API

--- 5) WEBSITE MAKER ↔ ASOLDI ---
[ ] WEBSITE_MAKER_BASE_URL=         (e.g. https://your-wm-host or http://localhost:3000)
[ ] Website Maker running and export API reachable from Asoldi server
[ ] Optional: firewall / VPN if WM is internal only

How: Set in Asoldi .env; test import from Sales tab with a real runId
